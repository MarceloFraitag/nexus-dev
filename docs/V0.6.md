# V0.6 — arquitetura e alterações

## Análise da V0.5

| Componente | Responsabilidade | Alteração na V0.6 |
| --- | --- | --- |
| frontend/src/main.tsx | Estado, navegação, explorador, conversa e composição da tela | Modos de foco, estado de layout, divisórias, navegação responsiva e importação dinâmica do editor |
| frontend/src/style.css | Temas originais e estilos de todas as funcionalidades | Preservado; minimal.css sobrepõe o layout legado |
| frontend/src/minimal.css | Nova camada visual | Grafite e roxo, menos decoração, espaçamento e modos para telas menores |
| frontend/src/components/ResizeHandle.tsx | Nova divisória reutilizável | Pointer capture, limites, teclado e atualizações por quadro |
| frontend/src/components/CodeEditor.tsx | Monaco e comparação | Integrações preservadas; módulo carregado sob demanda |
| frontend/src/lib/monaco.ts | Workers locais e temas | Fundo grafite e cursor roxo no tema principal |
| frontend/src/components/GitPanel.tsx | Status, stage, commit e diff | Preservado |
| frontend/src/lib/completions.ts | Autocomplete Ollama | Preservado |
| frontend/src/lib/api.ts | HTTP e streaming | Preservado |
| backend/app | FastAPI, arquivos, backups, Git e Ollama | Contratos preservados; versão atualizada |

A V0.5 já separava integrações importantes, mas concentrava estado e marcação em main.tsx. A V0.6 extrai a divisória e isola os novos estilos; a divisão completa de App em componentes menores permanece trabalho futuro.

## Preservação

Nenhum fluxo de Git, importação/exportação, busca, contexto, diagnóstico, patch, comparação, backup ou autocomplete foi removido. Painéis ocultos continuam montados para preservar o estado do editor. O tema alternativo 2077 continua disponível.

## Verificação

- 18 testes existentes do backend aprovados, incluindo operações reais de Git em pastas temporárias e testes de autocomplete/API.
- TypeScript e build de produção executados.
- Sem Ollama ativo neste ambiente: geração real de respostas e sugestões precisa ser conferida no computador local.
- Automação visual não executada: Chromium ausente e download do navegador falhou. Teste opcional em frontend/tests/layout.cjs (com Vite aberto, instale playwright com npm install --no-save playwright, execute npx playwright install chromium e node tests/layout.cjs).
- O Monaco mantém chunks grandes mesmo com carregamento sob demanda. Não foi feito benchmark de latência ou consumo.

## Conferência local

Importe exemplos/demo-python.zip, abra um arquivo, altere e revise com Ctrl+S. Confira o diff e o backup. Alterne os modos, arraste divisórias e reduza a janela. No Git, inicialize, faça stage, confira o diff e crie um commit. Com Ollama, envie uma pergunta e teste Ctrl+Alt+Espaço no editor.
